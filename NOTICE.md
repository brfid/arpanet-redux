# Asset, provenance, and licensing notice

This repository intentionally excludes third-party source checkouts, disk images, recovered IMP firmware, simulator binaries, generated media, and raw run logs. Source locations and exact revisions are recorded in [`pins/sources.lock.toml`](pins/sources.lock.toml), while known external asset identities are recorded in [`pins/arpanet-assets.sha256`](pins/arpanet-assets.sha256) and [`pins/pdp11-base-assets.sha256`](pins/pdp11-base-assets.sha256).

`make lab-setup` is an opt-in acquisition helper, not a redistribution mechanism. It clones the runtime source subset directly from the public upstream URLs in the lock file into the operator's external laboratory, selects exact commits, and builds local simulator executables. `make build-pdp11-base` downloads the two TUHS archives in [`pins/pdp11-base-inputs.lock.toml`](pins/pdp11-base-inputs.lock.toml) and assembles external disks whose identities are recorded in [`pins/pdp11-reconstructed-base.sha256`](pins/pdp11-reconstructed-base.sha256). `make install-pdp11-base` retains support for an operator-supplied legacy pair. These commands grant no permission to share what they obtain or produce.

The Ken Wellsch V6 distribution falls within the named PDP-11 UNIX versions in the [January 2002 Caldera license](https://www.tuhs.org/Archive/Caldera-license.pdf); retain and review that license's notices, conditions, and disclaimer before redistribution of covered material. This does not resolve the terms of every later addition in Tim Shoppa's RL02 image or the SRI/NOSC collection. The reconstruction reads Shoppa's first 512-byte boot block and the pinned NOSC kernel and daemon bytes only inside the external lab; those bytes and the resulting disks are never published here. The `eblanton/unix-v6-install` project remains an unlicensed methodology reference identified in the [original research note](docs/research/imp11a-device.md#v6-base-reproducing-the-pristine-root-filesystem); no code from its installer or tape converter is copied or required by the supported reconstruction.

The tested ARPANET in a Box revision has no bundle-wide root license, and its prepared assets do not share one clearly stated redistribution grant. The tested `linux-ncp` revision has no root license file. PDP-10/ITS uses mixed, file-scoped terms. SRI/NOSC Network UNIX V6 and its NOSC overlay also lack a root license that can safely be assumed to cover every included file. These are conservative engineering release boundaries, not legal conclusions.

The SIMH command files under [`config/`](config/) are minimal project-specific compositions written for the topologies in this repository. They invoke simulator commands and load external firmware or media at runtime; they do not include those external materials. Their provenance and runtime dependencies are documented in [`config/README.md`](config/README.md).

This repository's original work — orchestration code, project-authored SIMH configurations, documentation, ADRs, tests, and the scripts under [`scripts/`](scripts/) — is MIT-licensed; see [`LICENSE`](LICENSE). That license covers only what this repository actually contains and changes nothing about the paragraph above: `arpanet-in-a-box`, `linux-ncp`, PDP-10/ITS, the KA10 and H316 simulator forks, and every other source in [`pins/sources.lock.toml`](pins/sources.lock.toml) remain external material this project reads from or points at, under their own separately tracked terms. None of it is relicensed or vendored by this change. [`CREDITS.md`](CREDITS.md) acknowledges the principal software and preservation projects; detailed citations stay with the findings they support.

Do not publish firmware, guest binaries, disk images, source bundles, container layers, or derived system images until every included component has been reviewed independently. A checksum proves identity, not permission to redistribute.
