# Asset and licensing notice

This repository intentionally does not contain third-party disk images, recovered IMP firmware, simulator binaries, or source checkouts.

The tested ARPANET in a Box revision does not provide a bundle-wide root license, and the prepared assets inside it do not all share one clearly stated redistribution grant. The tested `linux-ncp` revision also has no root license file. PDP-10/ITS uses mixed, file-scoped terms. These observations are engineering release gates, not legal conclusions.

Source URLs, exact revisions, and evidence checksums are recorded so a user can reproduce a private laboratory without treating the upstream bundle as uniformly redistributable. Do not publish disk images, firmware, binary layers, or derived images until each included asset has been reviewed independently.

No license has yet been selected for the original files in this repository. Adding a repository license is a project-owner decision and does not resolve the separate terms of fetched or generated third-party material.
